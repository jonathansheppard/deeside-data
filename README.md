# Deeside in Data

numbers.json feeds the "Flintshire in numbers" strip on the Deeside in Data page on deeside.com.
Built on the Mac Mini by build_numbers.py from data Deeside.com already collects; yearly figures are kept by hand in manual.json.
Refreshed by emergency-feeds/push_site_data.sh at 07:15, 13:15 and 19:15.
